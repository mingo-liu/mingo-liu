# Terminal heading icon

`terminal.gif` is a transparent, 96 × 96 pixel animation displayed at 32 × 32
pixels beside `About Me`. Its green cursor blinks on a 1.3-second loop.

Source: [Lucide Terminal](https://lucide.dev/icons/terminal), commit
`70562c1ee1c4fdcf736fe97bc893fb8511927934`.
Modifications: green stroke and animated cursor.
